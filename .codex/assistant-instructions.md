# Instructions Assistant

## Usage
- Conserver dans ce dossier les conventions de travail demandees pour ce projet.
- Appliquer ces regles dans les prochains comptes-rendus et reponses liees au code.

## Liens de fichiers (retours assistant)
1. Dans les comptes-rendus, toujours fournir des liens de fichiers ouvrables dans l'IDE.
2. Format obligatoire: lien Markdown avec chemin absolu Windows prefixe par `/` pour ouverture IDE.
3. Avec ligne si necessaire: `C:\...\fichier.ts:42`.
4. Toujours utiliser des liens Markdown cliquables, pas des chemins en texte brut.
5. Pour citer plusieurs fichiers, chaque fichier doit avoir son propre lien.
6. Exemples:
   - `[service.ts](/c:/Users/samloba/Desktop/x-server-tauri-elysia-bun/x-server-tauri/apps/server/src/modules/webclient/common/service.ts)`
   - `[dal.ts:982](/c:/Users/samloba/Desktop/x-server-tauri-elysia-bun/x-server-tauri/apps/server/src/modules/webclient/pedagogie/dal.ts:982)`
