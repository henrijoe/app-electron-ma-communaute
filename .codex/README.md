# Dossier Codex

Ce dossier centralise les conventions de travail, la progression du projet et les notes de collaboration.

Fichiers:
- `assistant-instructions.md`: regles a appliquer dans les reponses et comptes-rendus.
- `desktop-blocking-flow.md`: explication detaillee du blocage automatique desktop, du superadmin et du debloquage.
- `progress.md`: historique court des actions realisees sur le projet.
- `notes.md`: espace libre pour ajouter de nouvelles consignes ou remarques.

Regle de maintenance:
- Ajouter une entree dans `progress.md` a chaque avancement important.
- Mettre a jour `assistant-instructions.md` quand une nouvelle convention devient stable.
